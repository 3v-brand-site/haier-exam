# 海尔空调维修测试

所有选手扫描同一个二维码进入考试。只需填写**姓名**和**网点名**，系统会从题库随机抽取 50 题（每题 2 分，满分 100 分）。多选题必须全部选对才得分。同一姓名和网点可以继续未交卷的考试，交卷后不能重考。

后台可查看姓名、网点、分数，并导出 CSV。

## 部署到 Render

本仓库是公开的，题库答案不在仓库里。

1. 把本仓库推送到 GitHub。
2. 在 Render 用 Blueprint 导入本仓库中的 `render.yaml`（新加坡区域、免费 Web 服务，并创建免费 Postgres 数据库 `haier-exam-db`）。
3. 首次同步时，在 Render 控制台手动填写以下环境变量（不要写入仓库）：
   - `ADMIN_PASSWORD`：后台登录密码
   - `QUESTIONS_JSON_B64`：题库文件的 gzip 后再做 base64 的编码值（由部署人员单独提供）
4. 部署完成后打开网站的 `/admin`，登录后台即可看到总二维码和成绩，也可导出 CSV。

说明：免费 Web 服务闲置后会休眠，本地磁盘不会保留；成绩保存在 Postgres。免费 Postgres 数据库创建后约 30 天到期，如需长期使用请升级。
